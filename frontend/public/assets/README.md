# Assets — Logos Nexus Bot Manager

Placez vos fichiers logo ici :

| Fichier | Usage | Taille recommandée |
|---------|-------|-------------------|
| `icone.png` | Favicon + icône d'application | 512×512 px |
| `logo-horizontal.png` | Écran de login, onboarding, zones larges | ~400×80 px |
| `petit-logo.png` | Sidebar compacte | ~32×32 px |

Les logos sont automatiquement utilisés dans :
- Sidebar : `petit-logo.png`
- Login / Setup : `logo-horizontal.png`
- Favicon : `icone.png`

Si les fichiers sont absents, des fallbacks CSS sont affichés automatiquement.
